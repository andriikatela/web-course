Розділ 1. Що таке Internet і Web

Щодня ми заходимо в інтернет зі свого телефону чи ноутбука. Ми навіть незамислюємося, як усе влаштовано.

Уся система правцює за правилом, яке називають взаємодією клієнта і сервера. Браузер на телефон - клієнт. Коли ми вводимо адресу сайту і тиснемо кнопку пошук, телефон (браузер) відправляє запит на інший компьютер-сервер. Цей сервер шукає потрібні файли сайту та відправляє їх назад на екран.

Internet — це величезна мережа, яка з'єднує комп'ютери по всьому світу. Web — це лише одна з послуг, що працює в цій мережі. Це сайти, які ми відкриваємо в браузері. Тому Internet і Web — не одне й те саме.

П'ять важливих термінів

URL
Адреса сайта в інтернеті, за якою браузер знаходить потрібну сторінку чи файл
HTTP
Протокол, за яким клієнт і сервер обмінюються запитами та відповідями
DNS
Система, що перетворює доменні імена на числові IP-адреси серверів
Браузер
Програма, яка надсилає запити, отримує файли сайту і показує їх на екрані
Сервер
Комп’ютер, що зберігає файли сайтів і відправляє їх клієнтам на запит

Історія виникнення Web

Всесвітню павутину придумав вчений Тім Бернерс-Лі.

Він вигадав посилання, щоб вчені могли легко ділитися статтями. З цього маленького проєкту народився сучасний Internet, без якого ми вже не уявляємо свого повсякденного життя.

Це сталося у 1989 році, коли Тім працював у лабораторії CERN. Перший сайт з'явився у 1991 році. З того часу сайтів стало мільярди.

Розділ 2. З чого зроблені Web сайти

На сторінці буде лише суцільний текст без абзаців та списків, клієнт просто закриє сторінку. Тому важливо ділити на маленькі шматки. Це допомагає очам читати і робить сторінку зручною для клієнтів.

Три головні технології розробки Web-сайту

  • HTML - створює каркас сайту
  • CSS - оформлення сайту, кольрів та шрифтів
  • JavaScript - оживляє кнопки та додає анімації

З чого складається HTML

Розділ 4. Культура написання коду в HTML

Потрібно дотримуватись простих правил щоб код можна було прочитати

  • Один заголовок h1
    • рівні заголовків не пропускаємо
    • рівень залежить від структури, а не від розміру шрифта
  • Вкладені елементи відокремлюються відступом
  • Кожен відкритий елеменет обов'язково закриваємо

Валідація

Браузер помилки виправляє мовчки, тому все виглядати може добре, але сам код з помилками. В такому випадку можна перевірити на сервісі W3C Markup Validation Service. Валідація коду допомагає виправити помилки.
